AutoRAG Lite · MCP Contract

검색 가능한 MCP 서버 지도

실제 src/mcp/server.ts 계약을 기준으로 만든 시각 문서입니다. 정적 tool, datasource별 동적 tool, 권한 경계, 오류 흐름을 한 화면에서 확인합니다.

2. tools/list에 노출되는 tool

READ
autorag.status

Index freshness, stale, component health를 조회합니다.

READ
autorag.search

method/datasource/local을 선택해 검색합니다. 선택은 backend 실행 전 적용됩니다.

READ
autorag.search.files

설정된 root 안에서 파일·폴더 이름만 찾습니다. 파일 내용은 읽지 않습니다.

READ
autorag.search.everything

Windows Everything provider를 호출합니다.

READ
autorag.datasources.list/get

authorized datasource의 description, capability, scope를 노출합니다.

READ
autorag.duplicates

Dupey로 exact/near/contains family를 검토용 스캔합니다.

WRITE
autorag.refresh

parsed mirror와 configured index를 갱신합니다. read-only mode에서는 숨겨집니다.

DYNAMIC
autorag.search_datasource_<id>

권한 있고 retrieval method가 등록된 datasource마다 생성됩니다.

4. 동적 tool 호출 계약

{
  "name": "autorag.search_datasource_slack",
  "arguments": {
    "query": "incident response",
    "topK": 5,
    "scope": "/slack/workspace"
  }
}
datasourceIds: ["slack"]와 local: false는 서버가 고정합니다.

5. 일반 검색 선택 규칙

입력실행 대상보안 의미
datasourceIds 생략authorized datasource methods + local methodsdenied datasource는 자동 제거
datasourceIds: ["slack"]Slack methods only다른 backend는 실행하지 않음
local: true선택 datasource + local methodslocal 추가는 명시적일 때만
local: falselocal methods 제외local 검색 경로 차단
methods 지정eligible set과 교집합unknown/unauthorized는 실행 전 거부
tags / scopetrusted 범위 안에서 결과 축소tool argument로 권한 확대 불가

8. 오류 contract

index-not-ready → autorag.refresh 호출 필요
stale-index → strict 검색이 stale index를 거부함
invalid-selection → unknown/unauthorized method 또는 datasource
duplicates-failed → Dupey 실행, timeout, JSON parsing 실패
datasource-not-found → authorized catalog에 없음
{
  "isError": true,
  "structuredContent": {
    "ok": false,
    "errorCode": "index-not-ready",
    "action": "autorag.refresh",
    "retryable": false
  }
}
